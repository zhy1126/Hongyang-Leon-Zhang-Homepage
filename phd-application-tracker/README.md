# 2027 PhD Application Tracker

Compact static tracker for the current shortlist: HKU, Northwestern, Stanford, NYU, Princeton, Michigan, Duke, Cambridge, UCL and Oxford OII.

The page contains public programme information only. Status values are stored locally in the browser with `localStorage`; no application documents or personal data are uploaded.

Open `index.html` directly, or publish the folder with GitHub Pages / another static host.
